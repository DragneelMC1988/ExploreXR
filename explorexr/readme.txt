== Installation ==

= Automatic Installation (Recommended) =
1. Go to **Plugins → Add New** in your WordPress dashboard
2. Search for **ExploreXR**
3. Click **Install Now** then **Activate**

= Manual Installation =
1. Download the plugin ZIP from [WordPress.org](https://wordpress.org/plugins/explorexr/)
2. Go to **Plugins → Add New → Upload Plugin**
3. Select the ZIP file and click **Install Now**
4. Activate the plugin via the Plugins menu

= Quick Start: Embed Your First 3D Model =
1. Go to **ExploreXR → Create Model** in the WordPress admin
2. Upload a GLB or GLTF file (GLB recommended — self-contained and fastest to load)
3. Set viewer size, camera controls, auto-rotation, and optional poster image
4. Copy the generated shortcode (e.g. `[explorexr_model id="123"]`)
5. Paste the shortcode into any post, page, widget, or page builder block
6. (Optional) Go to **ExploreXR → Free Add-on** to activate your free premium add-on

Full documentation: [https://expoxr.com/explorexr/documentation/](https://expoxr.com/explorexr/documentation/)

== Frequently Asked Questions ==

= What is the difference between the free version and Premium? =
The free version gives you a complete 3D viewer plus one free premium add-on of your choice (AR, Animation, Camera Controls, or Annotations). ExploreXR Premium is a full modular add-on platform where you choose up to 3 (Pro), 5 (Plus), or all 12 (Ultra) commercial add-ons — each activated individually so your site stays lean.

= Which 3D file formats does ExploreXR support? =
GLB, GLTF, and USDZ. GLB (binary GLTF) is the recommended format — it is self-contained, loads faster, has the broadest browser support, and compresses well with Draco. USDZ is optimized for iOS AR workflows via Quick Look.

= Which add-on can I activate for free? =
You can choose one of: AR (Augmented Reality), Animation, Camera Controls, or Annotations. Install it with one click from **ExploreXR → Free Add-on** in your WordPress admin. You can switch your choice at any time.

= How do I embed a 3D model on a WordPress page? =
Create a model under **ExploreXR → Create Model**, then paste the shortcode `[explorexr_model id="123"]` into any post, page, widget, or page builder block. That is all.

= Does ExploreXR require coding knowledge? =
No. The entire workflow — uploading models, configuring the viewer, embedding on pages, activating add-ons — is handled through the WordPress admin interface. No PHP, JavaScript, or CSS required.

= Does it work on all devices and browsers? =
Yes. ExploreXR works on all modern browsers and devices that support WebGL, including Chrome, Firefox, Safari, and Edge on desktop, tablet, and mobile.

= Will 3D models slow down my WordPress site? =
No, when configured correctly. Scripts and styles only load on pages that contain a 3D model. Multiple loading strategies (direct, lazy, and poster-driven for large files) let you control exactly when models load. Local Draco and Basis Universal decoders mean no external requests.

= Does ExploreXR work with Elementor, Divi, and Avada? =
Yes. All three work via shortcode in the free version. ExploreXR Premium adds native drag-and-drop widgets and modules for Elementor, Divi, and Avada.

= Is AR (Augmented Reality) included in the free version? =
Yes — as your free add-on choice. Select AR from **ExploreXR → Free Add-on** to install it. AR supports iOS Quick Look, Android Scene Viewer, and WebXR. Upgrading to Premium unlocks additional AR configuration options.

= Is ExploreXR compatible with WooCommerce? =
WooCommerce product page integration (attaching 3D models to products) is a Premium add-on. Basic shortcode embedding works in any WooCommerce product description in the free version.

= Is there a free trial for Premium? =
Yes — 14 days with full access to 4 commercial add-ons of your choice, no credit card required. [Request your trial here](https://expoxr.com/explorexr/trial-request/).

= Is ExploreXR compatible with WordPress 7? =
Yes. ExploreXR is tested against WordPress 7.x and follows WordPress Coding Standards for long-term compatibility.

= What happens to my models if I deactivate the plugin? =
Your model files and all settings are preserved. Deactivating the plugin does not delete any data. Reactivate and everything is exactly as you left it.

= Where can I get support? =
Free support via the [WordPress.org support forum](https://wordpress.org/support/plugin/explorexr/). Premium users get priority support at [expoxr.com/support/](https://expoxr.com/support/).

== Privacy Policy ==

ExploreXR does not collect, store, or transmit any personal data. All 3D rendering occurs entirely within the visitor's browser using locally bundled libraries. No external tracking, analytics, or user data collection is performed.

For free add-on installation, the plugin contacts the ExpoXR update server to download the add-on package. No personal user data is transmitted — only the request for the plugin file. For premium license validation, only a license key is sent to ExpoXR servers. See the [ExpoXR Privacy Policy](https://expoxr.com/legal/privacy-policy/) for full details.
