Adds advanced animation controls to the ExploreXR 3D model viewer. Requires ExploreXR Premium.

== Description ==

ExploreXR Animation Add-On extends the ExploreXR 3D model viewer with full animation control: play, pause, loop, ping-pong, and crossfade between animation clips embedded in your GLB/GLTF files.

**Requires ExploreXR Premium** and a valid license that includes the Animation add-on.

== Installation ==

1. Install and activate ExploreXR Premium first.
2. Upload the `explorexr-animation-addon` folder to `/wp-content/plugins/`.
3. Activate the plugin through the WordPress Plugins menu.
4. Go to ExploreXR → Animation Settings to configure.
