Adds augmented reality viewing to the ExploreXR 3D model viewer. Requires ExploreXR Premium.

== Description ==

ExploreXR AR Add-On enables AR viewing of 3D models via iOS Quick Look, Android Scene Viewer, and WebXR. Configurable AR button, placement options, and iOS/Android USDZ support.

**Requires ExploreXR Premium** and a valid license that includes the AR add-on.

== Installation ==

1. Install and activate ExploreXR Premium first.
2. Upload the `explorexr-ar-addon` folder to `/wp-content/plugins/`.
3. Activate the plugin through the WordPress Plugins menu.
4. Go to ExploreXR → AR Settings to configure.
